Kotonoha

Wayland 桌面歌词

Kotonoha 通过 D-Bus 读取 MPRIS 播放状态，在 Wayland 图层上显示逐字歌词。支持任意 MPRIS 播放器，无需播放器插件。

安装

Kotonoha 设置

01

任何 MPRIS 播放器，无需插件

通过 D-Bus 读取曲目和播放位置。播放器无需适配。播放位置用本地时钟插值，不逐帧查询。

02

四个歌词来源

来源顺序、匹配规则、回退和本地缓存都能配置。

Netease LRCLIB Kugou Cider Embedded lyrics

03

点击穿透

启用后，鼠标事件直接传给下层窗口。歌词层不拦截点击。

04

主题和语言都能跟随系统

浅色、深色，或跟随系统。界面语言也能跟随系统。设置首页就能改，改完立即生效，不用重启。

浅色 / 深色 / 跟随系统简体 · 繁體 · English

05

Wayland Overlay

能力 条件 行为
全屏上方显示 条件Wayland 合成器支持 wlr-layer-shell 行为KDE/KWin、wlroots 可浮在全屏窗口上方
毛玻璃 条件支持 ext-background-effect-v1 或 org_kde_kwin_blur 行为缺少时保留半透明，禁用毛玻璃

兼容性：不支持 wlr-layer-shell 的合成器（如 GNOME/Mutter）使用普通置顶窗口。

安装

Gentoo 用 gentoo-zh，Arch 用 AUR 的 kotonoha-git，NixOS 用 flake；也可以从源码构建。

sudo emerge --ask app-eselect/eselect-repository
  sudo eselect repository enable gentoo-zh
  sudo emaint sync -r gentoo-zh
  
  # live ebuild 没有任何关键字
  echo 'media-plugins/kotonoha **' | sudo tee /etc/portage/package.accept_keywords/kotonoha
  
  sudo emerge --ask media-plugins/kotonoha::gentoo-zh

Kotonoha

Linux 上的 Wayland 歌词
